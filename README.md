Cafe Sales Exploratory Data Analysis (EDA)

Project Overview

This project performs Exploratory Data Analysis (EDA) on a Cafe Sales dataset to identify patterns, trends, and relationships in customer transactions.

Dataset Features

- Item
- Quantity
- Price Per Unit
- Total Spent
- Payment Method
- Location
- Transaction Date

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Analysis Performed

- Dataset Overview
- Statistical Summary
- Missing Value Check
- Item Analysis
- Payment Method Analysis
- Histograms
- Boxplots
- Scatterplots
- Correlation Heatmap
- Pairplot Analysis

Key Findings

- Most purchased items were identified.
- Preferred payment methods were analyzed.
- Customer spending patterns were explored.
- Relationships between Quantity, Price Per Unit, and Total Spent were examined.
- Outliers and spending trends were identified.

Files Included

- cafe_EDA.ipynb
- cleaned_cafe_sales.csv
